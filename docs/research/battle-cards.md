# COS Sales Battle Cards — Tier 1 Competitors

> **Audience:** COS sales / pre-sales team. **One card per competitor — print-friendly.**
> **Source of facts:** every "attack here" gap below is a **cited fact** from
> [`competitive-landscape.md`](competitive-landscape.md) §2/§5 and
> [`kanna-competitive-analysis.md`](kanna-competitive-analysis.md). Do not add claims that are not in
> those docs. **Strategy behind these cards:** `competitive-landscape.md` §6–§7.
> **Date:** 2026-07-14.

**Legend:** 📊 = verified/cited fact · 📋 = positioning judgment · ⚠️ = internal honesty note (do not
say to the customer).

**The one rule (read first):** do **not** fight all four head-on. Pick the battleground where each is
structurally weak, own the **SME** segment none of them fully holds, and win on the two things **no
competitor has** — **AI-native "พูด/ถ่ายรูป/แชต → เอกสารอัตโนมัติ"** and **ราคากลาง / e-GP localization**.

**⚠️ Universal rep watch-out:** COS's edges (AI capture, deep offline, procurement→cost→finance) are
**built to spec but must be *demoed*, not just claimed**. In every card: **show it live, don't promise it.**

## 🥊 Card 1 — vs KANNA

**Threat:** HIGH — but only on site reporting. **What they are:** Japanese field/site-reporting app,
Bangkok office, Thai UI since 2022.

| | |
| --- | --- |
| ✅ **Do NOT fight (their strength)** | Field/photo UX (5 yrs polished), Bangkok office, Thai UI, Panasonic channel, enterprise seminars 📊 |
| 🎯 **Attack (their gap)** | **No procurement / PO / BOQ / cost / finance** — their data model has no vendor/PO/BOQ objects. Offline is **shallow + paywalled** (ProPlus+). Web "AI" is a help chatbot. 📊 |
| 💪 **COS wins by** | Match the wedge (report in < 2 min) but via **AI capture**, offline **free**, then **extend into the transactional layer KANNA can't follow without rebuilding its data model**. |
| 🏆 **Winning line** | *"KANNA จบแค่หน้างาน — COS ทำต่อจากหน้างานถึง PO / ต้นทุน / BOQ ในระบบเดียว"* |

**🎯 Discovery — open the gap:**
> *"หลังถ่ายรูป/ส่งรายงานหน้างานแล้ว ข้อมูลไหลไปออก PO คุมต้นทุน ทำ BOQ อัตโนมัติเลยไหม — หรือต้องคีย์ซ้ำใน Excel?"*

**🛡️ Objection handling:**

| ลูกค้าพูด | ตอบ |
| --- | --- |
| "เราใช้ KANNA อยู่แล้ว" | *"เก็บ KANNA ไว้ทำรูปหน้างานได้เลย — แต่ตอนสั่งของ คุมต้นทุน ทำ BOQ มันทำไม่ได้ ต้องกลับไป Excel. COS ทำต่อจากหน้างานถึงต้นทุนในที่เดียว ไม่ต้องคีย์ซ้ำ"* |
| "KANNA ก็มี offline" | *"ของ KANNA อยู่ tier เสียเงิน (ProPlus+) และตื้น — COS offline-first ฟรีตั้งแต่แรก และมี conflict resolution ตอนหลายคนแก้พร้อมกัน"* ⚠️ demo offline จริง |
| "KANNA มี AI แล้ว" | *"AI ของ KANNA บนเว็บเป็นแชตช่วยเหลือ — ของ COS คือพูด/ถ่ายรูปแล้วออกเป็นรายงาน/เอกสารให้เลย"* ⚠️ demo |

## 🥊 Card 2 — vs BUILK One Group

**Threat:** HIGH — entrenched Thai incumbent. **What they are:** Thai group — free BUILK Cost Control +
Yello materials marketplace + Pojjaman ERP; SCG/KBank/Krungsri/TQM-backed.

| | |
| --- | --- |
| ✅ **Do NOT fight (their strength)** | "Free" software + Yello materials margin + deep Thai cap table (SCG/KBank/Krungsri/TQM). **Don't fight on materials** or touch those bank/SCG channels. 📊 |
| 🎯 **Attack (their gap)** | **No BOQ / quantity-takeoff engine. No AI documented. Offline depth undocumented.** Software is a **loss-leader** for materials margin (~500M materials vs ~70M software) → they under-invest in software depth. 📊 |
| 💪 **COS wins by** | Be the **AI-native, BOQ-integrated OS their materials DNA won't fund.** Lead with **ราคากลาง-compliant BOQ** (BUILK has none). Counter the channel with **non-SCG materials** (INSEE Alliance / Do Home / Mega Home / Thai Watsadu). |
| 🏆 **Winning line** | *"BUILK ฟรีเพราะเขาขายวัสดุ — ซอฟต์แวร์เลยไม่ลงลึก. COS ขายซอฟต์แวร์ตรง ๆ เลยมี BOQ + AI + offline จริง"* |

**🎯 Discovery — open the gap:**
> *"ทำ BOQ / ถอดปริมาณงาน อ้างอิงราคากลาง ในระบบเดียวกับที่คุมต้นทุนได้เลยไหม?"*

**🛡️ Objection handling:**

| ลูกค้าพูด | ตอบ |
| --- | --- |
| "BUILK ฟรีนะ" | *"ฟรีเพราะโมเดลเขาคือขายวัสดุ ซอฟต์แวร์เป็นแค่ทางเข้า — เลยไม่มี BOQ ไม่มี AI. ถ้าอยากได้ BOQ + AI ที่ทำงานจริง COS คุ้มกว่าในระยะยาว"* |
| "เขามี Pojjaman ERP แล้ว" | *"Pojjaman เป็น ERP เดสก์ท็อป — COS เป็น AI-native + offline-first บนมือถือหน้างาน แล้วเชื่อ BOQ→PO→ต้นทุน→การเงินอัตโนมัติ ไม่ต้องคีย์ข้ามระบบ"* |
| "มี Yello ซื้อของได้ด้วย" | *"COS ไม่ผูกกับร้านวัสดุเจ้าใดเจ้าหนึ่ง — เปรียบเทียบราคาได้อิสระ และเชื่อมร้านนอกกลุ่ม SCG ได้"* |

## 🥊 Card 3 — vs ANDPAD ⚠️ most dangerous

**Threat:** HIGH & rising. **What they are:** Japan's full construction OS + strongest AI (Stellarc) +
Thai UI since Dec 2025. **This is the one COS can lose if it moves slowly.**

| | |
| --- | --- |
| ✅ **Do NOT fight (their strength)** | Full OS breadth + best AI + Thai UI + deep capital. **Don't chase Japanese-GC enterprise accounts or a long feature race** — they out-resource us there. 📊 |
| 🎯 **Attack (their gap)** | AI is **bolted onto form-based workflows. No Thai office** (SEA office = Vietnam). **No ราคากลาง / e-GP. Quote-only pricing** (no self-serve for SME). 📊 |
| 💪 **COS wins by** | (1) **Thai ground game** — local team + ราคากลาง/e-GP + SME focus; (2) **AI-native "พูด→เอกสาร"** leapfrogs form-bolted AI; (3) **speed** — take SME before they build a Thai GTM; (4) **self-serve / free entry** vs their quote-only wall. |
| 🏆 **Winning line** | *"ANDPAD ครบจริง แต่ทำจากญี่ปุ่น ไม่มีทีมไทย ไม่รองรับราคากลาง/e-GP — COS เป็นทีมไทย เข้าใจงานราชการไทย"* |

**🎯 Discovery — open the gap:**
> *"ระบบรองรับราคากลาง / e-GP สำหรับงานราชการไทยไหม? แล้วเริ่มใช้เองได้เลย หรือต้องขอใบเสนอราคาก่อน?"*

**🛡️ Objection handling:**

| ลูกค้าพูด | ตอบ |
| --- | --- |
| "ANDPAD ครบกว่า / เป็นแบรนด์ญี่ปุ่น" | *"ครบจริง แต่ทำจากญี่ปุ่น ไม่มีทีมในไทย ไม่รองรับราคากลาง/e-GP และ AI เป็นแบบกรอกฟอร์ม. COS ทีมไทย + AI แบบพูด/ถ่ายรูปแล้วออกเอกสารเลย"* ⚠️ demo AI = ตัวพิสูจน์ |
| "เขามี AI แล้ว (Stellarc)" | *"ของเขา AI ไปช่วยงานฟอร์มที่มีอยู่ — ของ COS เริ่มจากพูด/ถ่ายรูปได้เลย ไม่ต้องกรอกฟอร์มก่อน"* ⚠️ demo |
| "รอ ANDPAD เข้าไทยเต็มตัวดีกว่า" | *"ตอนนี้เขายังไม่มีออฟฟิศไทยและต้องขอใบเสนอราคา — COS เริ่มวันนี้ได้เลย รองรับราคากลางแล้ว"* |

**⚠️ Rep note:** window แคบ — ปิดเร็ว โฟกัส SME ไทย + ราคากลาง อย่าลากเป็นสงคราม feature.

## 🥊 Card 4 — vs Novade

**Threat:** MEDIUM-HIGH — enterprise end. **What they are:** Singapore enterprise field-ops + deep AI;
Thailand sales via reseller VR Digital.

| | |
| --- | --- |
| ✅ **Do NOT fight (their strength)** | Enterprise field-ops breadth + deep AI + Thai sales office (via reseller). **Don't contest enterprise/large-contractor RFPs** where Novade + VR Digital are entrenched. 📊 |
| 🎯 **Attack (their gap)** | **No procurement / BOQ / cost / finance. Enterprise-priced** (free ≤5 users, then $39/user). **Reseller-led**, not a direct SME motion. **Thai-language UI ⚠️ unverified.** 📊 |
| 💪 **COS wins by** | Own the **SME long tail** their enterprise + reseller economics can't serve; add the **transactional layer they lack**; go **product-led / direct**; be **verifiably Thai-native**. |
| 🏆 **Winning line** | *"Novade ทำสำหรับผู้รับเหมารายใหญ่ ขายผ่านตัวแทน — COS ทำสำหรับ SME ไทย เริ่มเองได้ และทำถึงต้นทุน/BOQ"* |

**🎯 Discovery — open the gap:**
> *"หลังเก็บฟอร์ม/ตรวจงานแล้ว ต่อไปออก PO คุมต้นทุน ทำ BOQ ในระบบเดียวกันได้ไหม? แล้ว UI เป็นภาษาไทยจริงไหม?"*

**🛡️ Objection handling:**

| ลูกค้าพูด | ตอบ |
| --- | --- |
| "Novade เป็น enterprise ระดับโลก" | *"ใช่ — ออกแบบสำหรับรายใหญ่ ราคาต่อ user และขายผ่านตัวแทน. COS ออกแบบสำหรับ SME ไทย เริ่มเองได้ ราคาเข้าถึงได้ และทำถึงต้นทุน/BOQ ที่ Novade ไม่มี"* |
| "เขามี AI ด้วย" | *"AI เขาอยู่ที่ฟอร์ม/ความปลอดภัย — แต่ไม่มี procurement/BOQ/ต้นทุน. COS ครบสายงานตั้งแต่หน้างานถึงการเงิน"* |
| "มีทีมขายในไทยแล้ว" | *"เขาขายผ่านตัวแทน (VR Digital) เน้นลูกค้ารายใหญ่ — SME อย่างเราดูแลได้ตรงกว่าและ UI ไทยเต็มระบบ"* ⚠️ Novade Thai UI ยังไม่ยืนยัน อย่าเคลมเกิน |
