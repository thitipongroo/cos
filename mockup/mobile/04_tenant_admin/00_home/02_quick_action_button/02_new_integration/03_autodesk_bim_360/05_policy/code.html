Data Collection

2. การใช้ข้อมูล

Usage of Data

ข้อมูลจะถูกนำไปใช้เพื่อการวิเคราะห์ความคืบหน้าของงาน การตรวจสอบความปลอดภัยในพื้นที่ และการจัดทำรายงานสรุปสำหรับผู้บริหาร โดยจะไม่มีการเปิดเผยข้อมูลแก่บุคคลภายนอกที่ไม่เกี่ยวข้องกับโครงการ

3. การคุ้มครองข้อมูล
