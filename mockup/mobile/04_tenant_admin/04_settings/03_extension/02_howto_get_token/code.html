Follow these steps to link your LINE Messaging API with Construction OS.

STEP 01 corporate_fare

Create a Provider

Go to the LINE Developers Console and create a new provider for your organization.

STEP 02 forum

Create a Messaging API

Select "Create a Messaging API channel" under your provider and fill in the required project details.

STEP 03 key

Issue Channel Access Token (v2.1)

Go to the "Messaging API" tab, scroll down to the bottom, and click "Issue" to generate your v2.1 token.
